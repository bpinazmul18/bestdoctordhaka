# SEO Skill — BestDoctorDhaka.com

## Purpose

This skill defines the SEO strategy, implementation standards, and technical SEO requirements for BestDoctorDhaka.com.

Project context:

- Healthcare directory
- Initial focus: Dhaka, Bangladesh
- Primary traffic strategy: Organic search
- Framework: Next.js
- Language: TypeScript
- Rendering: Next.js App Router
- Database: PostgreSQL + Prisma

SEO is a core product requirement.

Primary growth loop:

Google Search
→ BestDoctorDhaka page
→ Doctor/Hospital/Diagnostic discovery
→ Profile
→ Call / WhatsApp / Contact
→ Provider value
→ Featured listing / subscription

---

# Core SEO Principles

1. Build for users first.
2. Every indexable page must provide genuine value.
3. Search engines must be able to crawl and understand important public pages.
4. Use clean and stable URLs.
5. Use accurate metadata.
6. Use structured data only when it accurately represents visible content.
7. Avoid thin, duplicate, and automatically generated low-value pages.
8. Never keyword-stuff.
9. Never fabricate healthcare information.
10. Never fabricate doctor credentials, BMDC information, reviews, ratings, or hospital information.
11. Do not change existing public URLs without considering redirects and SEO impact.
12. SEO must never compromise healthcare data accuracy or user trust.
